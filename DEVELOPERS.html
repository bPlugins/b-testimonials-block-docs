Testimonials Block Developer Reference

For developers only. Everything the plugin registers under the hood, as of version 1.0.6. You do not need any of this to use the blocks. The user guide is DOCUMENTATION.html.

Post Type and Meta

The testimonial post type and its meta fields.

NameTypeDefaultDescription
testimonialpost typeNoneNot public, shown in the admin, available over REST. Supports title, editor and thumbnail. Carries its own testimonial_category taxonomy.
testimonials-blockpost typeNoneOne saved instance of the Testimonials block, locked to a single bptmb/b-testimonials block. Reached from Testimonials > Shortcode, and rendered wherever its [testimonials_block id=N] shortcode is placed.
bpbtb_ratingnumber5The star rating, 0 to 5, including half stars. Registered as REST-visible meta with a sanitize callback that clamps to that range; versions before 1.0.5 used absint here and rounded a fractional value down on save.
bpbtb_designationstringEmptyThe line under the name.
bpbtb_companystringEmptyThe reviewer's company.
bpbtb_emailstringEmptySet by the form only. Never rendered on the front end.

REST Routes

The two public-facing routes are POST only; two more are GET and editor-only.

NameTypeDefaultDescription
bptmb/v1/submitPOSTPublicThe Testimonial Form. Requires a name and a review, checks a nonce, and creates a pending testimonial. Also rate-limited, honeypot-checked and duplicate-checked; see A Submission Never Arrives.
bptmb/v1/submit-npsPOSTPublicOne poll vote. Requires a mark inside the block's scale.
bptmb/v1/review-sourcesGETEditorsEvery connected platform's current cached score and reviews. Requires edit_posts.
bptmb/v1/review-sources/(platform)GETEditorsOne platform's current cached score and reviews. What the editor calls to read or refresh a badge's live state. Requires edit_posts.

The testimonial post type also answers /wp-json/wp/v2/testimonial for logged-in users with permission, which is how the blocks list your reviews in the editor.

A worked example, emailing yourself whenever a review comes in:

add_action( 'bpbtb_testimonial_submitted', function ( $post_id ) {
    wp_mail(
        get_option( 'admin_email' ),
        'New testimonial awaiting review',
        get_edit_post_link( $post_id, 'raw' )
    );
} );

Blocks and Namespace

All blocks use the bptmb/ namespace and the bplugins editor category. bptmb/b-testimonials is the parent; the other thirty-nine name it as their parent, so they can only be inserted inside it.

Demo previews are served on the front page with the query argument bpbtb_demo=, and are limited to users who can edit posts.

In a PHP Template

To render reviews yourself, query the post type and read the three meta fields:

<?php
$reviews = get_posts( [
    'post_type'      => 'testimonial',
    'post_status'    => 'publish',
    'posts_per_page' => 6,
] );

foreach ( $reviews as $review ) {
    $rating      = (float) get_post_meta( $review->ID, 'bpbtb_rating', true );
    $designation = get_post_meta( $review->ID, 'bpbtb_designation', true );
    $company     = get_post_meta( $review->ID, 'bpbtb_company', true );
    ?>
    <blockquote>
        <?php echo wp_kses_post( $review->post_content ); ?>
        <cite><?php echo esc_html( get_the_title( $review ) ); ?></cite>
        <span><?php echo esc_html( $designation ); ?></span>
    </blockquote>
    <?php
}

The plugin's own helper does the same job and returns the shape its blocks use. See Helper Functions above.

CSS Custom Properties

The Colors panel writes CSS custom properties, and every stylesheet rule keeps its own value as fallback; you can set the same properties from your theme.

Every one of the forty blocks renders inside a wrapper carrying the class bTestimonials, so that is the selector to use when you want one set of values across the whole library:

.bTestimonials {
    --btb-accent: #0b81ee;
    --btb-surface: #ffffff;
    --btb-border: #e6e8f0;
    --btb-title: #101828;
    --btb-body: #344054;
    --btb-muted: #667085;
    --btb-star: #ff8c02;
    --btb-track: #f2f4f7;
}

Each block also carries its own class, so a single layout can be targeted on its own: the block name with the slash turned into a dash and wp-block- in front:

/* One layout only */
.wp-block-bptmb-testimonials-slider { --btb-accent: #16a34a; }
.wp-block-bptmb-google-review-badge { --btb-star: #fbbf24; }
Important

.wp-block-bptmb-b-testimonials is the classic single block and nothing else; it is not a wrapper around the other layouts, so styling it will not reach a grid, a slider or a badge. Use .bTestimonials for all of them.
