# Screenshot standard for DOCUMENTATION.html

Follow this for every new or updated image in docs-assets. It keeps the guide looking like one product.

## 1. What every step image must have

- One image for every numbered step that asks the reader to click, type, switch or open something.
- A red arrow on the exact control the step names. Not on a panel nearby. Not on a heading above it.
- Two arrows only when one step names two controls.
- Result images (a finished page, a front end view) need no arrow. Say so in the caption.

## 2. Show the whole screen

- Show the full editor or the full wp-admin page. Never crop down to one panel or one card.
- Editor: canvas on the left, sidebar open on the right, with the target panel scrolled into view.
- wp-admin: scroll the target into view, then take the full window.
- Take it at 1200 by 900, device scale 2.

## 3. Nothing from the site may leak in

- No black WordPress admin bar at the top. Crop the top 64 raw pixels, or hide it.
- No site name, no "Howdy, admin", no site menu, no site header or footer.
- No "Edit with Elementor" button or other third party buttons in the editor toolbar.
- No ads or "Available to install" lists from the block directory.
- No personal accounts, avatars, billing names or other projects. Blur or avoid them.
- Use the same demo data in every image: reviewer names, ratings, and category names must match the text.

## 4. The house frame

- Blue canvas, 56 px margin on all sides, white window with three traffic lights.
- Final width is 1195 px. Arrow is red, #EF4444.
- Arrow tail sits on empty space where it can, and the tip lands inside the control, not past it.
- Do not let the arrow cover the label it points at. Aim at the edge of the control instead.
- The arrow must never hide any text. Not the label, not a nearby heading, not a value. If the shaft crosses text, move the tail so it comes in from empty space. The tip may touch the control's edge, never the words.
- Every arrow has the same size on every image: same shaft thickness, same head size, same length range. Never scale an arrow with the image.

## 5. Captions

- Say what the reader sees and what the arrow marks. One or two short sentences.
- Plain words. No dashes, curly quotes, arrows, or ellipses in the text.

## 6. Check before you save

1. Open the final PNG. Is there an admin bar? A site name? A third party button?
2. Is the arrow tip on the control the step names?
3. Does the data match the text of the step?
4. Is the file bigger than 2 KB and listed in the guide?
5. Write the new file to a temp name, check the size, then rename it. Never write straight over DOCUMENTATION.html.
- Every image must be exactly 1195 x 928 px. Never a strip, never a long page; scroll the target into view instead.
- Admin notices (for example the review platform warning) must be hidden in shots; the tool now does it.
- Untitled test posts must never show: the tool hides '(no title)' rows in admin lists.
- The blue frame is exactly 56 px on all four sides of every image (window 1083 x 816). Never pad or letterbox; retake the shot at the standard viewport instead.
