Testimonials Block: Complete Setup & Customization Guide

Welcome to the Testimonials Block user guide. This guide shows you how to add customer reviews to your WordPress site, choose a layout, change the design, collect new reviews and reuse the same testimonials on other pages.

You do not need coding skills or a technical background. Follow the steps in order and you can build your first testimonial section without learning WordPress developer terms.

Before You Begin

Make sure you have the following:

  • A WordPress website where you can install plugins.
  • Administrator access so you can install and activate Testimonials Block.
  • At least one real customer review that you want to show on your site.
  • A customer photo if you want to display one. This is optional.

After installation, start with How To Use. The first setup will teach you the basic workflow before you explore the extra features.

Install and Activate the Plugin

First, install Testimonials Block from your WordPress dashboard.

Install from WordPress

  1. Log in to your WordPress dashboard and go to Plugins > Add Plugin.
  2. Search for Testimonials Block. Find the plugin by bPlugins and click Install Now.
  3. When installation finishes, click Activate.

Check That It Is Ready

After activation, a new Testimonials menu appears in the left side of your WordPress dashboard.

That is all you need for the basic setup. You can now create your first testimonial section.

Optional

If you already have the plugin ZIP file, you can also use Plugins > Add Plugin > Upload Plugin and upload the ZIP instead.

How To Use

Now create a page or post, add the Testimonials block, enter your reviews and publish the section.

Add the Testimonials Block to Your Page or Post

Go to Pages or Posts and open the page where you want to show customer reviews.

  1. Click the black + button to open the Block Inserter.
  2. Search for Testimonials and click the Testimonials block.

The block will appear on the page with a layout picker.

Choose Your Testimonial Style

Select the design you want from the layout picker. You can change it later, so choose the one that is closest to the look you want.

If you want to compare more designs, open the full layout picker. See Choose Another Testimonial Layout.

Add Reviews and Customer Details

Each testimonial card can contain the customer's name, job title or role, review text, star rating and photo.

  1. Select the block and open the General tab.
  2. Open Add or Remove Testimonial Cards and click a card.
  3. Replace the sample Name, Designation, Review and Rating with your real customer information.
  4. Add a customer photo in the image field if you want to show one.

Click Add New Card to add another testimonial. Use Duplicate when you want to copy the same card setup, or Remove when you do not need a card.

Adjust Columns and Spacing

Use the layout settings to control how many testimonial cards appear in one row and how much space sits between them.

  1. Open the Layout panel under the General tab.
  2. Set Columns for desktop, tablet and mobile.
  3. Adjust Column Gap and Row Gap until the cards have enough space.

Use the device preview at the top of the editor to check tablet and mobile layouts.

Customize Colors, Fonts and Cards

Open the Style tab when you want the testimonial section to match the rest of your website.

  1. Open the Card panel to change the card background, border and shadow.
  2. Open the text panels to change the name, designation and review fonts and colors.
  3. Open the Image panel if you want to change the customer photo size or border.

For a full explanation of these controls, see Customize Your Testimonial Design.

Publish and Test Your Testimonial Section

When the section looks right in the editor, click Publish or Update.

Open the live page and check that the reviews, star ratings, photos and spacing look correct. Also resize the browser or use the mobile preview to make sure the section works on smaller screens.

Great, your first testimonial section is now live.

Save Reviews and Reuse Them

If the same customer review will appear on several pages, save it once under the Testimonials menu instead of typing it again in every block.

WordPress can keep testimonials in their own saved area, separate from normal pages and posts. WordPress calls this a Custom Post Type (CPT). In this plugin, the option appears as Testimonials (CPT), which simply means: use the reviews saved under the Testimonials menu.

Save a New Review

  1. Go to Testimonials > Add New Testimonial.
  2. Type the customer's name in the title field.
  3. Type or paste the review in the main content area.
  4. Add the rating, designation and company in Testimonial Details.
  5. Add a featured image if you want to show the customer's photo.
  6. Click Publish.

View Your Saved Reviews

Go to Testimonials > All Testimonials. This screen keeps your saved reviews in one list so you can edit them later.

Next, use those saved reviews inside any testimonial block. See Use Saved Reviews in a Block.

Use Saved Reviews in a Block

After you save reviews under the Testimonials menu, you can load them into a testimonial block instead of typing each card by hand.

The Content Source setting tells the block where its reviews should come from. Manual uses reviews typed directly into that block. Testimonials (CPT) loads reviews you already saved under the Testimonials menu.

Choose Saved Testimonials

  1. Select the testimonial block and open the General tab.
  2. Open Content Source.
  3. Change Source from Manual to Testimonials (CPT).

The block now reads from the reviews you saved under the Testimonials menu.

Choose Which Reviews to Show

Use these simple controls when you do not want to show every saved review:

  • Category — show one group of saved reviews.
  • Number — choose how many reviews the block should load.
  • Order By — choose whether WordPress should sort by date or title.
  • Order — choose newest-to-oldest or oldest-to-newest.

Show One Category

Categories are useful when you want separate sections for different products, services or years.

  1. Go to Testimonials > Categories and create the groups you need.
  2. Assign the saved reviews to those categories.
  3. Return to the block and choose the category under Content Source.

Only reviews from that category will appear in the section.

Collect Reviews from Visitors

Use the Testimonial Form block when you want customers to send a review directly from your website.

When a visitor sends the form, the plugin saves that review as a submission. You can check it before anything appears publicly on your site.

Add the Review Form

Add the Testimonial Form layout to a page just like any other Testimonials layout. Publish the page so visitors can open the form.

What the Visitor Can Send

The form can collect the customer's name, review text, rating and photo. Some fields can be optional depending on the form settings.

Approve Reviews Before They Appear

New reviews do not have to appear on your site immediately. They first go to Testimonials > Submissions, where you can check them.

Open a submission and choose whether to approve it, reject it or delete it. Approve only the reviews you want to publish.

Good to know

If a visitor uploads a photo, use a normal JPG, PNG, GIF or WebP image under the plugin's upload limit.

Show Google and Facebook Reviews

If your business already has reviews on Google or Facebook, you can show your real rating and reviews on your site.

A review source is the place a review comes from. Connect it once and the plugin keeps the numbers fresh for you.

Open Review Sources

  1. In your WordPress dashboard, click Testimonials, then Review Sources. You will see one card for Google and one for Facebook.

Connect Google Reviews

Google needs two things: a Place ID and an API key. The Place ID tells Google which business you mean. The API key is like a password for your review data. Both are free.

Get your Place ID

  1. Open Google's Place ID Finder. Type your business name and click it on the map. Copy the Place ID.
  2. On the Google card, paste it into Place ID.

Get your API key

  1. Open the Google Cloud API Library and sign in. If Google shows its terms page, pick your country and click Agree & continue.
  2. Click Select a project at the top.
  3. Pick a project, or click New project to make one.
  4. Search for Places API and press Enter. Click Places API (New). The plain Places API will not work.
  5. Click Enable.
  6. Click APIs & Services, then Credentials.
  7. Click Create credentials, then API key.
  8. In the panel that opens, click Select API restrictions and tick only Places API (New). Then click Create and copy the key.
  9. Back on the Google card, paste the key into API key.

Google may ask you to add billing before it lets you turn on the API. You then see this box. Click Create billing account and follow the steps.

Good to know

Normal use stays free, because the plugin checks only about once a day.

Check that it works

  1. Click Save, then Test & fetch now. Your real rating and review count appear on the card.

Connect Facebook Reviews

Your Facebook Page needs Recommendations turned on, with at least one recommendation.

  1. On the Facebook card, click Connect with Facebook. A popup opens.
  2. Log in with the account that manages your Page, allow access, and choose your Page if you have more than one.
  3. The popup closes. You now see a green CONNECTED label and your rating.

Import Reviews into Your Saved Testimonials

A connected card shows a live score. You can also import the written reviews, so they behave like testimonials you typed yourself.

  1. Click Testimonials, then Import / Export. Under Import from Google and Facebook, click Import for your platform.

After import, you can edit, categorize and reuse those reviews.

Choose Another Testimonial Layout

Testimonials Block includes many layouts, but you do not need to learn them all. Pick a layout based on what you want visitors to see.

Open the Layout Picker

  1. Select your testimonial block.
  2. Open Select / Switch Block on the General tab.
  3. Click Change Block / Layout.
  4. Choose a layout from the window and click Use This Layout.

Choose by What You Want to Show

  • Grid layouts — best when you want several reviews visible at the same time.
  • List layouts — good for longer reviews that need more reading space.
  • Slider and carousel layouts — useful when you want reviews to move one at a time.
  • Marquee layouts — useful for a continuously moving strip of reviews.
  • Spotlight and story layouts — best when one strong customer story should stand out.
  • Badges and rating layouts — best when you want to show a score, trust badge or rating summary.
  • Forms and feedback layouts — use these when visitors should submit a review or answer a recommendation question.

Your review text and customer information stay in the block when you switch layouts. Only layout-specific design settings may change.

Customize Your Testimonial Design

Use the Style tab to match the testimonial section with your website colors, typography and spacing.

Change the Card Background, Border and Shadow

Open the Card panel on the Style tab. From here you can change the background color, padding, border and shadow.

Use the hover settings if you want the card to change slightly when a visitor moves the mouse over it.

Change the Customer Photo

Open the Image panel to change the photo width, height, border and outer ring.

Change Names, Roles and Review Text

Open the typography panels for the Name, Designation and Review Text. You can change the font, size, weight and color.

Set Different Values for Desktop, Tablet and Mobile

When a control has device icons, choose the device first and then set the value. For example, you can show three columns on desktop, two on tablet and one on mobile.

Tip

Start with the large screen first, then check tablet and mobile. This makes it easier to see which values really need to change.

Plugin Dashboard and Settings

Most of your work happens in the page editor. Use Demo & Help when you want to preview layouts, hide layouts you never use, or change settings that affect the plugin as a whole.

Open Demo & Help

Go to Testimonials > Demo & Help.

Preview Layouts

Open Demos to see the available testimonial designs on your own site before you use them.

Turn Layouts On or Off

Open All Blocks when you want to hide layouts your team never uses.

Switch a layout off to remove it from the block picker. The main Testimonials block is required and cannot be turned off.

Choose What Happens When the Plugin Is Deleted

Open Settings to choose what should happen to your saved plugin data if you delete Testimonials Block from WordPress. The delete data on uninstall option removes that saved data together with the plugin.

Leave this option off if you may reinstall the plugin later or want to keep your saved testimonials. Turn it on only when you are sure you want the plugin data removed during uninstall.

View Feedback and Recommendation Scores

The Feedback & NPS Poll asks visitors how likely they are to recommend you on a scale from 0 to 10, then summarizes the answers for you.

NPS stands for Net Promoter Score. It is a common way to measure customer recommendation using those 0–10 answers. The plugin calculates the result for you, so you only need to read the summary.

Open the Results Screen

Go to Testimonials > Feedback & NPS Poll.

Read the Main Results

  • Recommendation score — the overall score from the 0–10 answers.
  • Total responses — how many people answered.
  • Average score — the average number selected.
  • Promoter percentage — the share of visitors in the highest recommendation group.

The bars below show how many visitors selected each number.

Clear Test Votes

When you finish testing, use Clear All Responses if you want to start with an empty result screen. This removes the saved poll responses, so use it only when you really want to reset the data.

Show Testimonials Anywhere with Shortcodes

A shortcode is a small piece of text inside square brackets that tells WordPress what to show. You paste the shortcode into a page, and visitors see the testimonial or testimonial layout instead of the code itself. There are two kinds: a Classic Shortcode for one review, and a Block Shortcode for a full layout.

Classic Shortcode: Show One Review

  1. Go to Testimonials > All Testimonials.
  2. Find the Classic Shortcode column and copy the code for the review.
  3. Open the page where you want the review. Click the + button at the top, search for Shortcode and click the Shortcode block.
  4. Click inside the block and paste the code.

Publish or update the page, then view it on the front end to make sure the testimonial appears where you placed the shortcode.

Block Shortcode: Show a Full Layout

This one shows a full layout, such as a grid or slider, made in the block editor. The code looks like [testimonials_block id=N].

  1. Go to Testimonials > Shortcode. Click the blue code in the Block Shortcode column to copy it.
  2. Open the page where you want the layout. Click the + button at the top, search for Shortcode and click the Shortcode block.
  3. Click inside the block and paste the code.
  4. Click Publish, then view the page. If the page is already live, the button says Update instead. The full layout shows where you placed the code.

Use It in Elementor

Elementor has its own Shortcode widget. Both the Classic and the Block shortcode work in it.

  1. In Elementor, search for Shortcode and drag the Shortcode widget onto the page.
  2. Paste your shortcode into the Enter your shortcode box.
  3. Click Publish, then view the page. If the page is already live, the button says Update instead. The review shows where you placed the widget.

FAQs & Troubleshooting

Find quick answers to common questions and simple fixes for the problems users run into most often.

Common Problems and Fixes

A Layout Is Missing

Go to Testimonials > Demo & Help > All Blocks and make sure that layout is switched on.

Sample Reviews Appear on the Live Page

Open Add or Remove Testimonial Cards and replace or remove every sample card you do not want to publish.

My Changes Do Not Show on the Live Site

Click Update first. If you still see the old version, clear any saved cache from your WordPress caching plugin, your hosting provider or a service such as Cloudflare. A cache is simply a stored copy of the page that can make an older version appear for a while.

A Slider or Marquee Does Not Move

Open the layout's movement settings and make sure autoplay is enabled. Also check that the block has enough reviews to move through.

A Google or Facebook Badge Shows Old Data

Open Testimonials > Review Sources and click Test & fetch now on that platform.
